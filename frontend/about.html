🛡️ About the project

Audit any GitHub repo
like a senior engineer.

CodeShield AI scans a repository's code for leaked secrets and common vulnerabilities, maps its architecture, and turns everything into one clear score with actionable recommendations.

What it checks

Five engines, one report.

🔑

Secret detection

9 regex patterns hunt for API keys, tokens, private keys and credentials accidentally committed to the repo.

🐞

Vulnerability scan

9 vulnerability classes — SQL injection, XSS, command injection, hardcoded secrets, insecure randomness and more.

🧩

Framework detection

17 framework indicators identify Django, Flask, FastAPI, React, Next.js, Spring and others from project files.

🗂️

Language mapping

40+ language mappings break the codebase down by language, files and lines of code with visual charts.

🏛️

Architecture review

7 best-practice checks — README, license, tests, CI, .gitignore, docs and dependency manifests.

📊

One clear score

Everything rolls up into a single 0–100 score and a letter grade from A+ to F, with prioritized fixes.

How scoring works

Transparent, deterministic, no black box.

55%

Security

Secrets and vulnerabilities found in the code, weighted by severity.

45%

Architecture

Project hygiene — docs, tests, CI, licensing and structure.

Grades run from A+ (90+) down to F (below 40).
